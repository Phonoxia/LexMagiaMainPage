# Lex Magia - Mainpage
This repository contains the Lex Magia homepage, currently hosted at [rpg.bollmann-hb.de](https://rpg.bollmann-hb.de). 
## Installation
### Requirments
Your Server or local installation needs a way to execute php-files(Version 8.2 or later, tested up to 8.5).
### Install
Clone the repo to an emtpy folder.
```sh
git clone https://github.com/Phonoxia/LexMagiaMainPage.git
```

If you need downloads functionality, manually create 'downloads' as a folder in the root of the project.

Ensure your webroot or root of execution is the root folder. If you changed this, you will need to change all links in css and php files.

If all is well, you should be able to see all code on a browser of your choice.
